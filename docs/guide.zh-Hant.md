# CandleDrill 使用教學

依 2026-10-08 在 v0.2.0 的實測撰寫，並按 v0.2.1 更新；原文：<https://propfirmsdrama.com/2026/10/08/candledrill-guide/>。截圖只在原文，本檔不嵌入圖片。

CandleDrill（K線操練場）是免費、開源、在自己電腦運行的K線回放練習工具：逐根回放、模擬落單、盲練與交易日誌，資料全部留在本機。這篇是作者自己的使用教學。介面文字與數字以該次實測為準；v0.2.1 改過的字句，下面寫的是現在的介面，不是當日畫面。

它回答一個具體問題：想用歷史K線練落單、練止蝕、練守規則，但不用付月費，也不用把資料交給網站。

## 安裝：四行指令

需要 Node.js 22 或以上與 npm。在終端機貼上：

```bash
git clone https://github.com/Kinfxhk/candledrill.git
cd candledrill
npm ci
npm start
```

然後用瀏覽器打開 <http://127.0.0.1:4870/>。2026-10-08 在 Mac 上照做一次成功，`npm ci` 約一兩秒完成，不需要 C++ 編譯工具。README 另附 Docker 方式，一樣只開放本機 `127.0.0.1`；該次沒有測 Docker。

原始碼以 AGPL-3.0-or-later 授權。README 承諾永久免費，沒有收費解鎖、試用期或次數限制，沒有廣告、沒有追蹤、不需要帳戶。資料預設存於 `~/.candledrill/candledrill.db`。該次測試中，瀏覽器沒有向外部發出任何請求。

## 第一步：產生示範數據或匯入 CSV

第一次打開，資料庫頁是空的。選擇「產生示範數據」或「匯入 CSV」。示範數據代號 `SYNTH-DEMO`、標示「合成」，共 10,200 根 1 分鐘K線，覆蓋 2026-01-05 08:00 至 2026-01-30 16:29。它由程式按亂數種子生成，不是真實市場價格。

選定數據集，右邊會出預覽圖。左下「練習紀錄」列出所有練習，可以打開或刪除。截圖見[原文](https://propfirmsdrama.com/2026/10/08/candledrill-guide/)。

匯入自己的 CSV，對話框會問分隔符、第一行是否標題、欄位對應、時間格式、UTC 時差等。介面寫明：「只匯入你有權使用的數據。CandleDrill 永遠不會上傳到任何地方。」故意給錯的 CSV 會匯入失敗，並逐行列出原因。

「最小跳動（跳）」在匯入對話框的預設值是 0.01。旁邊有一句：「預設為 0.01。期貨常用其他最小跳動（例如 0.25）。止蝕、止賺及盈虧都用這個數值。」匯入之後，數據集列表會顯示該最小跳動。記得改成自己品種的跳動，否則止蝕、止賺與盈虧會計錯。

## 第二步：設定練習帳戶與規則

「開始新練習」的表單，2026-10-08 實測如下。最小跳動不是寫死的 0.25：選定數據集後，表單會填入該數據集的跳動；示範數據實測是 0.25。欄位名稱是 v0.2.1 的介面原文（「跳」，不再寫 tick）。

| 欄位（v0.2.1 介面原文）    | 該次見到的值       | 示範一設定 |
| -------------------------- | ------------------ | ---------- |
| 起始資金                   | 50000              | 50000      |
| 最小跳動（跳）             | 0.25（跟示範數據） | 0.25       |
| 每 1.0 點價值              | 50                 | 50         |
| 每張合約單邊手續費         | 2.5                | 2.5        |
| 市價／止蝕單滑價（跳）     | 1                  | 1          |
| 每日虧損上限（留空＝不設） | 留空               | 1000       |
| 追蹤回撤（留空＝不設）     | 留空               | 2000       |
| 盈利目標（留空＝不設）     | 留空               | 3000       |

表單其餘欄位有練習名稱、回放開始時間（預設約在數據五分之一位置）、交易所 UTC 時差、交易日開始時間，以及盲練開關。表單上有一句：「規則在每根K線收市時檢查，盤中觸及不會即時平倉。」

## 第三步：逐根回放與雙圖表

工具列有播放／暫停、下一根、+10、速度與「跳到」。速度預設是 `5×/s`（每秒 5 根）。把時間跳到 2026-01-13 10:00，時鐘立刻對上。時間框可選 1m、5m、15m、1h、1D。「雙圖表」並排兩個時間框；「連動圖表」讓兩邊十字線與時間軸同步。快捷鍵（介面原文）：

| 快捷鍵    | 動作       |
| --------- | ---------- |
| 空白鍵    | 播放／暫停 |
| →         | 下一根     |
| Shift + → | +10        |
| B         | 買入       |
| S         | 沽出       |
| F         | 平倉       |
| Esc       | 取消畫線   |

## 第四步：落單、止蝕與止賺

右邊「落單」面板有市價、限價、觸價單三種。止蝕與止賺以跳計，留空就是不設。面板寫明：「市價單由最後收市價起計，而不是由成交價起計。」「持倉」顯示方向、平均價、未平倉盈虧、已實現盈虧（含手續費）與權益。已實現盈虧旁邊註明：「已計入已付手續費，包括尚未平倉前的入場手續費。」圖上會標出入場與出場位置，止蝕止賺以虛線顯示。

示範一做了三筆交易，以 R（每單位風險的回報）計：

| #   | 做法                                        | 結果                                 | R     |
| --- | ------------------------------------------- | ------------------------------------ | ----- |
| 1   | 市價買入 1 張，止蝕 8、止賺 16 跳           | 08:25 止賺 3953.00 成交，淨賺 182.50 | 1.62  |
| 2   | 限價買入 2 張 @ 3953.25，止蝕、止賺各 12 跳 | 同一根先成交、再碰止蝕，淨虧 335     | −1.12 |
| 3   | 按 S 鍵市價沽出 1 張，止蝕 10、止賺 20 跳   | 止蝕 3961.75 成交，淨虧 155          | −1.13 |

兩個細節。第一，市價單的止蝕由最後收市價起計。第一筆設止蝕 8 跳，由收市 3949.00 起計。實際入場是開市價加 1 跳滑價的 3949.25。真實風險變成 9 跳，所以 R 不會剛好等於設定的倍數。

第二，同一根K線同時碰到止蝕與止賺，程式保守地先算止蝕。第二筆就是限價成交後，同一根K線再碰止蝕。介面亦寫：「成交模型：訂單只會在之後的K線成交；同一根K線同時觸及止蝕及止賺時，假設先觸止蝕。」

## 畫線與 R 工具

工具列有水平線、趨勢線、矩形、好倉 R、淡倉 R 與清除畫線。v0.2.0 實測時掣上寫的是「長倉 R」「短倉 R」；v0.2.1 中文已改為「好倉 R」「淡倉 R」，與持倉面板的「好倉」「淡倉」一致。

實測好倉 R：在入場價點擊，預設止蝕 20 跳、目標 40 跳。圖上標籤原文是「好倉・風險 20 跳（每張 250.00）・回報 40 跳・2.00R」。算式：20 跳 × 0.25 × 每點 50 元 ＝ 250。畫線會儲存在練習內。提示句是：「在入場價點擊，再拖曳控制點設定止蝕及目標。」

## 練習規則：要知道它在收市才檢查

示範二設每日虧損 300、追蹤回撤 600、盈利目標 400，從 2026-01-14 09:30 回放，市價買入 6 張、不設止蝕。09:30 那根K線由 3905.00 跌到 3901.75。

收市時權益跌穿每日上限，以收市價減滑價 3901.50 平倉。這筆淨虧 1,155。沒有止蝕，交易表的 R 仍顯示 `N/A`；滑鼠提示是「不適用：這筆交易有入場未設止蝕，無法計算 R」。買入與沽出按鈕隨即變灰。

v0.2.0 頂部橫額寫的是英文原因：「已觸發練習規則：daily loss limit 300。已停止落單，你仍可繼續回放檢討。」v0.2.1 起，同一句的原因已譯成中文：「已觸發練習規則：每日虧損上限 300。已停止落單，你仍可繼續回放檢討。」出場原因、訂單類型與練習狀態同樣有中文；存檔裡的代碼仍然是英文。

規則在每根K線收市時才檢查，盤中觸及不會即時平倉。上限 300，一根 1 分鐘K線已經虧了 1,155。現時的收市檢查，最適合用來練控制張數與止蝕。盤中（按最高最低價）檢查仍在 CHANGELOG 的計劃內，尚未做。

## 盲練：不讓記憶幫你作弊

開新練習時勾「盲練」。說明是：「隨機起點、隱藏日期，價格以整數個跳動單位移到另一個水平。盈虧及規則完全一樣。揭曉或完成之前，這個數據的預覽會隱藏。」

2026-10-08 的畫面代號顯示 BLIND。時鐘只寫「第 1 日 · Tue 14:36」，不顯示日期。v0.2.1 起，中文介面的星期是週一至週日，同一位置會寫「週二」，不再寫 Tue；揭曉前仍然只有第幾日、星期與時間，沒有曆法日期。示範數據原本約 3,900，該次盲練圖上變成 6,800 多。

按「揭曉」後，橫額顯示（該次原文）：

> 已揭曉：SYNTH-DEMO，真實時間 2026-01-13 13:57 → 2026-01-13 14:36（交易所時間）；圖上價格等於真實價格 +2985.5。

揭曉之後，時鐘改為真實交易所時間，格式是 `YYYY-MM-DD HH:MM`，與橫額的真實時間是同一時刻。圖上價格維持位移，這是設計：揭曉只還原時鐘與橫額上的真實代號、時段和價差，不把圖上的價格改回去。

README 講明它只防一眼認出，並非加密保證。用途是避免你記得某日走勢，練習時只能按圖決定。

## 交易日誌、統計、匯出與備份

底部分頁有交易、交易日誌、統計、成交與匯出。每筆交易可以加標籤（逗號分隔）與筆記，自動儲存。

每筆都顯示 MAE 與 MFE，即持倉期間最差與最好的價格走勢。介面註明：由平均入場價計，單位為跳及 R，按入場K線至出場K線每根的最高及最低價計算。交易日誌另有按開倉時段（交易所時間）與開倉星期的統計；中文介面的星期表用週一至週日。

示範一的統計分頁：

| 項目       | 數值        |
| ---------- | ----------- |
| 交易數     | 3           |
| 勝率       | 33.3%       |
| 淨盈虧     | −307.50     |
| 每筆期望值 | −102.50     |
| 盈利因子   | 0.37        |
| 平均 R     | −0.21       |
| 最大回撤   | 490（1.0%） |
| 已付手續費 | 20          |

匯出有三種：交易 CSV、HTML 報告與練習 JSON。CSV 已包括標籤與筆記欄；HTML 報告是單一檔案，不連外部網址。

該次按下「備份全部」，下載一個約 0.5 MB 的 `.db` 檔。「由備份還原」在 CHANGELOG 與 README 的描述是：先唯讀檢查檔案，再在一筆交易內換上，舊資料庫另存為 `candledrill.db.before-restore-<時間>`。還原這一步該次沒有實測。
